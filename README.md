# dsh-mcloud

把 **中国移动云盘（139）** 接进 DeepSeek Harness：在会话页顶部加一个「移动云盘」页签，
可以直接浏览、上传、下载、转移网盘文件；同时给模型提供一整套 `mcloud_*` 工具。

## 快速开始

**环境要求**

| 项目 | 要求 |
| --- | --- |
| DeepSeek Harness | **>= 0.2.1-rc.5，< 0.3.0** |
| Node.js | >= 22 |
| 系统 | Windows |

**五步用起来**

1. 装插件（见下方「安装」）
2. 重启 DSH —— 插件在 profile 启动时加载
3. 会话页顶部标签栏点「**移动云盘**」
4. 用**扫码**或**账号密码**登录（全新安装一定是未登录状态）
5. 看到容量和文件列表 → 可以用了

之后可以直接让 AI 操作网盘，也可以右键菜单自己动手。

## 安装

最省事：在 DSH 的「添加插件」里输入包名：

```
dsh-mcloud
```

或者用命令行：

```powershell
dsh plugin --profile desktop add dsh-mcloud
```

也可以从 GitHub 装：

```powershell
dsh plugin --profile desktop add github:GIYN-S/dsh-mcloud
```

或下载 Release 里的 tgz：

```powershell
dsh plugin --profile desktop add https://github.com/GIYN-S/dsh-mcloud/releases/download/v0.3.4/dsh-mcloud-0.3.4.tgz
```

本地开发用 link：

```powershell
dsh plugin --profile desktop add "link:/path/to/dsh-mcloud"
```

装完**重启 DSH** 才生效。

## 登录

打开面板会看到登录页，两种方式任选。

### 扫码登录（推荐）

点「**开始扫码登录**」→ 弹出一个浏览器窗口 → 手机扫码 → 完成。

- 不需要输密码
- 凭据会自动续期，日常**不需要反复扫码**
- 弹出的是独立 profile 的浏览器，不影响你日常用的 Edge

### 账号密码登录

在「账号密码」页签填手机号/邮箱和密码。

- **密码默认只用一次**，登录成功后立刻丢弃
- 勾选「**记住密码**」才会保存，用 Windows DPAPI 加密存在本机

### 退出登录

面板里点「退出登录」，会清掉本机凭据，回到未登录状态。

### 凭据存在哪

`%USERPROFILE%\.dsh-mcloud\authorization.dpapi` —— 当前用户的 DPAPI 加密，
换用户或换机器都解不开。想换位置在配置里写 `credentialDir`。

**不要把凭据贴到 Issue、聊天记录或截图里。**

## 功能

### 面板内操作

界面是资源管理器风格：左边文件夹树，右边文件列表。

| 操作 | 说明 |
| --- | --- |
| 浏览目录 | 左侧点文件夹，右侧显示它的内容；也可双击右侧文件夹进入 |
| 返回上级 | 点面包屑跳回任意一层，或点左侧文件夹树 |
| 调整侧栏宽度 | 拖动文件夹树与列表之间的分隔线，双击恢复默认 |
| 容量 | 顶部栏底部的一条通栏进度线，数值居中显示 |
| 调整列宽 | 拖动「大小」两侧的竖线，双击恢复默认 |
| 搜索 | 顶部搜索框，在当前目录及子目录中按文件名查找 |
| 上传 | 右键 → 上传文件 / 上传文件夹 / 拖动上传 |
| 下载 | 右键 → 下载到本地 / 打开下载直链 / 下载整个文件夹 |
| 转移 | 右键 → 转移到…（选择目标文件夹） |
| 复制路径 | 右键 → 复制路径 |
| 重命名 / 删除 | 右键菜单（文件夹的右键菜单只有「复制路径」和「重命名」） |

**下载目录**：左上角「下载到」按钮，点开可以手填路径，或点「选择目录」用系统对话框逐级选。

**传输进度**：面板底部有一条固定的进度条，空闲时是一条淡色细线。传输时变粗变蓝，
显示文件名与百分比；完成后保持 5 秒再缓缓淡出。

## 使用提醒

- **大文件或整个目录**：让模型调用 `mcloud_upload`，走本机路径直传，效率最高。
  面板里的上传需要经过浏览器中转一次。
- **下载整个文件夹**不是压缩包：移动云盘没有打包下载接口，插件会递归遍历后逐个下载。
- **删除进回收站**，可以在网盘里恢复。
- **写入类操作会弹审批**，这是 DSH 的安全机制，不是出错。
- **列表滚动到底会自动加载下一批**，不需要点按钮；看过的目录会被缓存，再次进入很快。
- 如果长时间不用，登录凭据可能过期，届时重新登录即可。

## 配置

可选，在 profile 的 `cordis.patch.yml` 里：

```yaml
- id: dsh-mcloud
  name: 'dsh-mcloud'
  config:
    credentialDir: '/custom/credential/dir'   # 凭据目录
    enableWrites: false                        # 设为 false 则关闭写入审批闸（不建议）
    # 仅当你在 DSH 前面挂了反代 / 用自定义域名访问时才需要：
    allowedAuthorities: ['dsh.example.com']
```

## 安全说明

`/api/dsh-mcloud/*` 是一组挂在本机 webServer 上的接口，能读写你已登录的云盘。
DSH 的 `webServer.register` 只按路径分发、**不做** Host / Origin 准入，所以插件自己
带了一道闸（`lib/request-guard.js`），每条路由都会过：

- **Host** 必须是本部署自己的 authority（环回 / 监听器绑定 IP / `allowedAuthorities`），
  且端口要对得上监听器；
- **Origin** 必须与 Host 同源，`null` 直接拒；
- **`Sec-Fetch-Site: cross-site`** 一票否决。

这挡住的是 DNS rebinding 和「你用浏览器打开恶意网页、它替你打本机接口」这两类攻击。
注意 `x-dsh-mcloud: 1` 这个请求头**只是标记，不是安全边界** —— 任何网页都能自己加，
真正起作用的是上面三条。

`npm test` 跑安全回归（24 项，含 4 条攻击路径）。

## 文件结构

```

lib/request-guard.js 请求闸：Host / Origin / DNS rebinding 防护
lib/login.js         账号密码登录
lib/scan-login.js    扫码登录
lib/transfer.js      上传下载的传输层
lib/client.js        会话页面板（登录页、文件浏览、右键菜单、传输进度）
cordis.patch.yml     bundle patch
locale/*.json        面板标题与描述
test/                安全回归测试（node --test）
```
